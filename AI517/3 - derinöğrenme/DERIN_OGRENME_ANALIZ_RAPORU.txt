KULLANILAN MODELLER:
-------------------

1. ÖZEL CNN MODELİ (Convolutional Neural Network)
   - Mimari: 4 Convolutional katman + 3 Dense katman
   - Katmanlar:
     * Conv2d(3→32) → MaxPool2d → BatchNorm2d
     * Conv2d(32→64) → MaxPool2d → BatchNorm2d
     * Conv2d(64→128) → MaxPool2d → BatchNorm2d
     * Flatten → Linear(512) → Dropout(0.5) → Linear(3)
   - Parametreler:
     * Optimizer: Adam
     * Learning Rate: 0.001
     * Loss Function: CrossEntropyLoss
     * Batch Size: 16
     * Epochs: 5
   - Özellikler:
     * Sıfırdan eğitildi
     * BatchNormalization ile hızlı öğrenme
     * Dropout ile overfitting önleme

2. VGG16 TRANSFER LEARNING MODELİ
   - Mimari: VGG16 (ImageNet'te önceden eğitilmiş) + özel sınıflandırıcı
   - Katmanlar:
     * VGG16 features (donduruldu)
     * VGG16 classifier (değiştirildi)
     * Linear(4096→3) - 3 sınıf için
   - Parametreler:
     * Optimizer: Adam
     * Learning Rate: 0.001
     * Loss Function: CrossEntropyLoss
     * Batch Size: 16
     * Epochs: 5
   - Özellikler:
     * Transfer learning (önceden öğrenilmiş özellikler)
     * Sadece classifier katmanları eğitildi
     * ImageNet'te öğrenilen genel özellikler kullanıldı
