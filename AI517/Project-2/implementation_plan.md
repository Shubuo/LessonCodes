# Turkish Stress Detection: Migration from NMT to LLM/Generative Paradigm

## Background

The v1 approach used MarianNMT with Gemini API to generate synthetic data, focusing on translation quality (BLEU, BERTScore). This yielded:
- **5,545 word-level emphasis examples** ([vurgu_varyasyonlari.csv](file:///Users/buraky/1-CODE/0-Lessons/AI517/Project-2/legacy/vurgu_varyasyonlari.csv))
- **2,465 syllable-level emphasis examples** ([vurguHece.csv](file:///Users/buraky/1-CODE/0-Lessons/AI517/Project-2/legacy/vurguHece.csv))

The new paradigm shifts focus from **translation** to **stress detection** using sequence labeling with Turkish-specialized models (BERTurk).

## User Review Required

> [!IMPORTANT]
> **Data Quality**: Legacy datasets are generated by Gemini API with rule-based templates. We will validate samples and may need to filter low-quality examples.
